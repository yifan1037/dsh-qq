# QQ 分身 · 使用说明

> 面向用户，不是开发者文档。看完就能用。

---

## 一、这套东西是什么

你的 DSH 里有一个能聊 QQ 的「她」。消息链路是：

```
QQ（你手机/电脑上的聊天窗口）
  ⇅
SnowLuma（登录 QQ 的协议端，必须自己装）
  ⇅
dsh-qq-native 插件（跑在 DSH 里）
  ⇅
DSH 会话（她的记忆、人设、上下文都在这）
```

**没有中间的桥接进程了**——插件直接跟 SnowLuma 说话。

---

## 二、启动顺序（每次开机）

| 顺序 | 要启动什么 | 说明 |
|---|---|---|
| 1 | **SnowLuma** | 不启动 = QQ 收不到也发不出 |
| 2 | **DSH** | 插件随 DSH 启动；日志在 `~/.dsh/qq-native/plugin.log` |
| 3 | **QQ 管理台**（可选） | 看状态、调权限、管记忆，不开也能聊天 |

打开管理台（推荐用独立窗口）：

```
http://127.0.0.1:3101/?token=<consoleToken>
```

- `consoleToken` 在 `~/.dsh/qq-personal/settings.json` 里
- 不带 token 会显示 401，这是正常的

## 三、管理台各页面

| 页面 | 干什么 | 常用度 |
|---|---|---|
| **总览** | 三个状态灯（DSH / QQ / SnowLuma）、当前生效配置 | ⭐⭐⭐ |
| **人设** | 选/编辑她的角色卡 | ⭐⭐ |
| **原生链路** | 显示当前会话 id、合并窗口、主动/爱好/屏幕开关状态 | ⭐⭐ |
| **日志** | 插件运行日志（排障第一站） | ⭐⭐⭐ |
| **成本** | 今日/每日 token 花费、每条会话成本 | ⭐⭐ |
| **会话** | 她现在的对话、未读数、策略 | ⭐ |
| **记忆** | 记忆库：查看/搜索/添加/删除 | ⭐⭐⭐ |

| **探索** | 屏幕监控、爱好、L5 探索记录、命令记录 | ⭐⭐ |
| **任务** | 任务队列（新建/推进/完成） | ⭐⭐ |

顶部四个芯片：

```

```

## 四、在 QQ 里怎么用

### 4.1 普通聊天

直接发消息，**不需要任何前缀**。

```
你：在吗
她：在的呀 (´｡• ᵕ •｡`)
```

### 4.2 连发多条

1.6 秒内连发的几条会**合并成一次回复**，不会一句一回。

### 4.3 让她闭嘴

她如果回了 `[SILENT]`，说明这轮她选择不说话（这是设计好的，不是坏了）。

### 4.4 让她记住一件事

她会自己在回复里写：

```
记：主人今天体测提前完成，挺开心的
```

这行**不会发到 QQ**，而是进记忆库。你也可以直接说「记住我今天体测提前完成了」。

### 4.5 看屏幕

| 你说 | 她做什么 |
|---|---|
| `看屏幕` | 截一张 → 描述 → 回你 |
| `开屏幕监控` | 每 5 分钟自己看一眼（画面变了才记录） |
| `关屏幕监控` | 立刻停 |

**只读**：只能截图，不能动鼠标键盘。

### 4.6 让她干活

普通聊天模式下她只能读文档。要让她改文件、跑命令：

1. 管理台 → **权限** → 勾「L2 电脑操作」（或 L4 探索）
2. 管理台 → **权限** → 打开「工作模式」
3. QQ 里直接说需求

工作模式下她用的是 `qq-work` 预设（有 pwsh、文件读写、任务工具）。

---

### 4.7 群聊

管理台 → 探索页 → 群聊配置：打开开关、填群号白名单、按需设关键词/档位/冷却。

档位：0-10 只回 @、10-20 加关键词、20-90 按概率、90-100 全都接。

### 4.8 让她看图

直接发图给她；图片会存到 `~/.dsh/qq-native/media/`，她用 `read_image` 看（只能读这个目录）。

### 4.9 人设自述

| 你说 | 效果 |
|---|---|
| `看自述` | 把当前自述发给你 |
| `回滚人设` | 回到上一个备份 |
| `强制改自述` | 重置今天的修改额度 |

她也会在回复里用 `[自述: …]` 自己写。

### 4.10 记忆总库

管理台 → 记忆页 → 记忆总库：可搜索所有历史记忆（含删掉的）。

### 4.11 她能做的 QQ 操作

30 个 `qq_*` 工具：好友/群/成员/历史/群文件/群公告查询、点赞、已读、撤回、发文件、合并转发、处理申请；
群管理（公告/群名/名片/禁言/头衔）需在权限页打开 `admin`；踢人/退群/删好友需 `destructive`（默认关）。
## 五、权限怎么理解

| 名字 | 她能做什么 | 风险 |
|---|---|---|
| **L2 电脑操作** | 截图、看界面、鼠标键盘 | 中（能操作软件） |
| **L3 全盘只读** | 读任意位置的文件 | 中（能看隐私文件） |
| **L4 探索模式** | 执行命令、读写文件 | 高 |
| **L5 自主探索** | 到点自己醒来逛允许目录 | 中（无人看着） |
| **工作模式** | 用工程工具（pwsh/fs/tasks） | 高 |

**紧急停止**：管理台 → 权限 → 「紧急停止」，一键关掉所有电脑能力，聊天不受影响。

## 六、记忆怎么工作

- 每轮聊天她会看到：**印象（关于你的短标签）+ 记忆库索引 + 最近几句话**
- 记忆库会自动整理：去重、按类别分组、生成索引
- 你可以随时在管理台「记忆」页搜索/添加/删除
- 文件位置：`~/.dsh/qq-memory/`
  - `memories.jsonl` 主库
  - `INDEX.md` 整理后的索引（人也能读）
  - `memories-archived.jsonl` 归档（不删除）

---

## 七、她自己的时间

你没说话的时候，她也会"过日子"：

| 行为 | 频率 | 产出 |
|---|---|---|
| **L5 探索** | 你设的时间点 | 逛允许目录 → 汇报 + 记记忆 |
| **爱好时间** | 每天 ≤2 次（白天） | 小本子里的随笔（`data/hobby-log.jsonl`） |
| **主动找你** | 4 小时没说话、白天、每天 ≤3 次 | 发一条 QQ |

管理台 → 探索页能看到爱好清单和最近的随笔；「原生链路」页能看到各项开关。

## 八、成本

管理台 → 成本页：今日花费、每日明细、会话统计。

> 统计每 5 分钟更新一次，不是实时。

想省钱：

- 关掉「主动找话题」或调大空闲阈值
- 屏幕监控间隔调大（默认 5 分钟）
- 爱好时间关掉（`config.json` → `hobby.enabled = false`）

## 九、常见问题

| 现象 | 怎么办 |
|---|---|
| **QQ 没回复** | 看 `~/.dsh/qq-native/plugin.log`：有没有「收到消息」→「已回复」 |
| **她回两遍** | 检查是不是还有别的进程在发（旧桥接、多个插件实例） |
| **管理台打不开** | 确认 DSH 在跑；地址带 `?token=` |
| **管理台页面卡在加载中** | 看浏览器 F12 Console 报错，发开发者 |
| **她的回答像失忆** | 检查会话 id 是不是旧窗口（管理台「原生链路」页有显示） |
| **静音/不说话** | 检查是不是开了紧急停止 |
| **SnowLuma 在线但她收不到** | SnowLuma 的 WS 端口（默认 3011）和 token 对不对 |
| **改了配置没生效** | 插件部分配置需要重启 DSH；屏幕/爱好开关 20 秒内自动同步 |

## 十、数据在哪（备份就备份这些）

```
~/.dsh/qq-native/
├── config.json          她的配置
├── state.json           会话 id + 最近对话
├── plugin.log           运行日志
├── data/persona.md      人设卡
├── data/social-v2.json  印象库
├── data/hobbies.json    爱好
├── data/hobby-log.jsonl 爱好随笔
├── state/token-usage.jsonl  成本记录
├── state/l5-runs.jsonl  L5 运行记录
└── screen/              截图表

~/.dsh/qq-memory/
├── memories.jsonl       记忆库
├── INDEX.md             索引
└── memories-archived.jsonl  归档

~/.dsh/qq-personal/
├── settings.json        管理台设置（含 consoleToken）
├── capabilities.json    权限状态
└── tasks/               任务队列
```

**整个 `~/.dsh/qq-native` + `~/.dsh/qq-memory` 拷走就等于备份了她。**

## 十一、关掉某些功能

| 想关什么 | 怎么关 |
|---|---|
| 主动找话题 | 管理台「原生链路」页，或 `config.json` → `proactive.enabled = false` |
| 爱好时间 | `config.json` → `hobby.enabled = false` |
| 屏幕监控 | 管理台勾掉，或 `screenWatch.enabled = false` |
| L5 探索 | 管理台「权限」页关掉 L5，或清空允许目录 |
| 全部电脑能力 | 管理台「权限」→ 紧急停止 |
| 回复全部 | `config.json` → `enableReply = false`（只观察不回） |

## 十二、版本

管理台右上角显示当前版本，鼠标悬停能看到三个组件各自版本：

- 插件 `dsh-qq-native`：核心链路
- 管理台 `dsh-qq-personal`：界面
- 预设 `qq-agent-presets`：人设/工具组合

升级：替换插件目录 → 重启 DSH。

---

## 十三、已知限制（别期待）

- **只有私聊**，没有群聊
- **不能发图片/表情/语音**
- **不能引用、不能拍一拍**
- 未读水位是简化版（靠消息去重）
- 成本统计有 5 分钟延迟
- 聊天和调度共用一把锁（同一时刻只做一件事）

---

## 十四、出问题了怎么恢复

1. **聊天还在，但功能乱了**：管理台 → 权限 → 紧急停止 → 逐项重开
2. **插件起不来**：看 `plugin.log`，或临时把 `enableReply` 设为 false 让它"只看不回"
3. **想完全回到桥接时代**：见仓库里的 `ROLLBACK.md`（改两个配置 + 重启 DSH）
4. **数据救急**：把上面第十节的目录整个备份，出问题先留证据再动手
