# 路线图

- [x] 私聊收发（OneBot v11 / SnowLuma）
- [x] 消息合并（1.6s 窗口 + 6s 上限 + 去重）
- [x] 分条发送（≤3 气泡）
- [x] 记忆注入（印象 + 索引 + 最近对话）
- [x] 记忆写入（`记：` 行）+ 自动整理（去重/分组/INDEX.md）
- [x] 人设注入（首轮）
- [x] 会话复用 / 接旧窗口
- [x] L5 自主探索
- [x] 任务队列续跑
- [x] 主动找话题
- [x] 成本统计
- [x] 屏幕监控（只读）+ 眼睛会话
- [x] 爱好时间
- [x] 管理台（总览/人设/原生链路/日志/成本/会话/记忆/权限/探索/任务）
- [x] 版本号显示 + 使用说明

## v0.2（计划）

按优先级：

1. **引用回复**（`replyToMessageId`）—— 一条字段的事，体验提升明显
2. **收图**（下载 + 传给模型）—— 需要图片内容块
3. **发表情包 / 发图** —— OneBot 图片段
4. **拍一拍** —— 一个 API
5. **真正的未读水位** —— 按 `message_seq` 而不是 message_id 去重
6. **按会话的权限** —— 群聊前先有隔离

## v0.3（候选）

- **群聊**：群白名单 + @/关键词触发 + 档位（复用桥接的设计）
- **语音**：收（转文字）/ 发（TTS）—— 成本最高，收益最低，最后做
- **主动行为更聪明**：结合最近话题/时间/她的日程，而不是纯空闲计时
- **管理台多语言**（英文 / 中文）
- **一键安装脚本**（Windows）

## 版本策略

- `0.x` 阶段：小版本（0.1 → 0.2）可以有不兼容变更，CHANGELOG 里写清
- `1.0` 之后：语义化版本，配置项只增不删（删要 deprecation 周期）
