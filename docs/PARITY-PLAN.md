# 优化方向：让 agent 拥有「用户在 QQ 上能做的一切操作」

> 目标不是「把框架做成全能 bot」，而是：**用户能在 QQ 客户端上做的事，她也能做**——
> 但每一步都受权限、审计和节奏约束。

---

## 一、能力对齐矩阵

按 OneBot v11 的 API 面 + QQ 客户端实际行为整理。
状态：✅ 已支持 ｜ ❌ 未支持 ｜ 🔒 需权限 ｜ ⛔ 不建议做

## 二、架构影响

现在插件只有「收文本 → 回文本」一条链路。要支持全面操作，需要加三层：

### 1. 消息段（segment）序列化/反序列化

```
内部统一表示：
[{ type: 'text', text }, { type: 'image', file }, { type: 'reply', id }, { type: 'at', qq }]
  ⇅ 编解码
OneBot v11 消息段数组 / CQ 码
```

- 收：把段转成「给模型看的内容块」+ 「文本摘要」
- 发：把模型输出的结构化指令转成段数组

### 2. 动作层（Action API + 工具面）

新增 `lib/onebot-actions.mjs`：把 OneBot 的 `send_private_msg` / `delete_msg` / `upload_private_file` / `set_group_card` 等封装成
**agent 可调用的工具**（MCP 或 DSH 工具），并带：

| 机制 | 作用 |
|---|---|
| 权限映射 | 每个动作挂在 L1–L5 某一级上，默认关 |
| 审计日志 | 每个动作写 `state/actions.jsonl`（谁、什么、参数、结果） |
| 频率限制 | 每群/每人每分钟上限（防刷、防封号） |
| 二次确认 | 发文件、群管理、删好友类动作先回问一句 |
| 幂等/去重 | 同一条消息不重复操作 |

### 3. 事件面扩展

```
现在：message/private
新增：message/group、notice/*（撤回/入群/禁言/拍一拍）、request/*（好友/入群）
```

事件要进「时间线」（给 agent 看最近发生了什么），而不是每个都触发回复——
否则群里会变成话痨。

---

## 三、分阶段

| 阶段 | 内容 | 验收 |
|---|---|---|
| **P0（必须先做）** | 引用回复、发图片、收图片/表情（模型能看图）、消息段编解码 | 私聊里发图她能看到并接话；能引用回复 |
| P1 | 表情包、拍一拍、撤回、群聊基础（白名单 + @/关键词触发 + 档位） | 群里 @ 她会被叫到；能回表情包 |
| P2 | 文件收发、群文件、好友/群列表、请求处理、点赞、已读 | 能发文件；能处理入群申请 |
| P3 | 语音（TTS/STT）、合并转发、群公告、群名片 | 可选项 |
| ⛔ | 群管理（禁言/踢人）、加删好友、改资料、重启 | 明确不做 |

---

## 四、安全与节奏（和「能做一切」同等重要）

| 原则 | 实现 |
|---|---|
| 默认最小权限 | 所有动作默认关，按需开 |
| 群聊不是复读机 | 档位（@/关键词/概率）+ 冷却时间 |
| 敏感动作要确认 | 发文件、群管理、删好友：先问再做 |
| 不越界 | 不做批量加好友、不群发、不做反检测 |
| 可审计 | 所有动作落日志，管理台可查 |

---

## 五、需要确认的三件事

1. **群聊**：是「必须支持」还是「只要私聊」？（决定 P1 的范围）
2. **账号级操作**（好友/群管理/改资料）：全部不做，还是只做只读查询？
3. **媒体发送策略**：她想发图/文件时直接发，还是先问一句「要发吗」？

## 七、已确认的取舍（2026-10-28）

| 问题 | 决定 |
|---|---|
| 群聊 | **做**（P1 起，白名单 + @/关键词 + 档位 + 冷却） |
| 账号级操作 | **都做**（只读查询 + 请求处理 + 群管理 + 资料类，全部实现） |
| 媒体发送 | **直接发**（受权限与频率限制，不逐次确认） |

### 但保留两条硬约束

1. **破坏性动作仍需二次确认**：踢人、禁言、删好友、退群、改资料——
   实现上先回一句「要我踢掉他吗？」等确认。媒体类（图/表情/文件）按决定直接发。
2. **权限分层不能省**：所有动作默认关，管理台按级打开；
   群管理类单独一级（L5+），和普通聊天分开。

### 因此阶段调整为

| 阶段 | 内容 |
|---|---|
| **P0** | 消息段编解码、引用回复、发图片/表情、收图片（模型能看图）、动作层基础（权限+审计+限流） |
| **P1** | 群聊（收/发/@/撤回/档位）、拍一拍、表情包 |
| **P2** | 文件收发、好友/群列表、请求处理、点赞、已读、群文件 |
| P3 | 语音、合并转发、群公告、群名片 |
| 需确认 | 踢人/禁言/删好友/退群/改资料（实现但默认关，动作前先问） |
